# Vision 2.0 — UX Design System (Local Companion)

**Status:** Binding for Phase 05c  
**Date:** 2026-08-02

## Doctrine
- Product is a **local companion**, not a map browser.
- First viewport: brand + one job (For You, plan, or ask) — not a dashboard of cards.
- Real place photography / atmosphere as visual anchor when possible.
- Intentional motion: (1) Avatar idle/notify, (2) plan timeline progress, (3) soft sheet transitions.
- Avoid Google Maps chrome, purple-glow AI clichés, and fear UI for safety data.

## Client surfaces
| Surface | Job |
| --- | --- |
| For You / Plans | Persona packs + progressive plan timeline + emergency strip |
| Search | Universal search → safe detail → add to plan / ask / report |
| AI Chat | Grounded answers + plan builder + why-chips |
| Saved | Favorites + plans; open companion |
| Profile | Identity, hard filters, language |

## Floating AI Avatar
- Draggable overlay; snap to corners; never fully block primary CTAs.
- States: idle (breathe), notify (badge + soft pulse), speak (chat active), celebrate (plan saved), soft-warn (replan available — calm copy).
- Tap → sheet: unread cues, Open chat, Continue plan, Hide for session.
- Reduce-motion: static icon + badge only.
- RTL: dock flips with layout direction.

## Guide surfaces
- Contribution workspace (knowledge types), not discovery map.
- Map = my zone (green circle) + SubGuide borders.
- Team: Add SubGuide → draw border → Waiting Admin.

## Admin
- Confirm SubGuide queue: parent zone vs drawn border map, formation note, Approve/Reject.
